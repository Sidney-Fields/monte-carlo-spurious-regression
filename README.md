# Monte Carlo Simulation of Spurious Regression

Independent econometrics simulation project examining the behaviour of hypothesis testing under spurious regression conditions in persistent time-series data.

## Objectives
- Investigate spurious regression behaviour
- Analyse persistence in AR(1) processes
- Evaluate distortion in statistical inference

## Methods
- Monte Carlo Simulation
- AR(1) Time-Series Processes
- OLS Regression Estimation
- t-Statistic Analysis

## Key Findings
- Persistent time-series processes significantly increased false rejection rates
- Statistical inference became increasingly unreliable as persistence strengthened

## Tools Used
- R
- ggplot2
- Matrix algebra and simulation methods
